# Kejser Gallery – kunsti rendi kalkulaator

Üheleheline maandumisleht: kunsti rent kuumaksega ja fotovõtete päevarent koos hinnakalkulaatoriga.

- Kõik on failis `index.html` (HTML, CSS ja JavaScript).
- Hinnad muudad faili lõpus objektis `PRICING` (kuurent 3%, päevarent 50 €, miinimum 150 €, soodustused).
- Päringuvorm `rendipaering` käib Netlify Formsiga. Teavitused tulevad e-postile (seadistus Netlifys: Forms → Form notifications).
- Logo on failis `img/kejser-logo-valge.svg` (valge, optimeeritud).
- Privaatsuspoliitikas tuleb täita vastutava töötleja nimi ja registrikood.
